# T4P (Tech for Players)

## Опис проєкту
**T4P** — це онлайн-магазин для продажу персональних комп’ютерів та конфігуратор для створення власних збірок. Сайт розроблено в рамках курсу "Веб-розробка програмного забезпечення".

Мета проєкту — створити зручний інтерфейс для вибору ПК (ігрових, офісних) з можливістю фільтрації та оформлення замовлення.

## 🛠 Технологічний стек (Лабораторна робота 3)
У проєкті реалізовано сучасний адаптивний дизайн без використання JavaScript-бібліотек (Pure CSS).

### Використані CSS-технології:
* **CSS Modules:** Стилі організовано за модульним принципом для зручності підтримки (`base`, `layout`, `components`).
* **Flexbox:** Використано для побудови навігаційного меню, вирівнювання елементів у шапці та футері, а також для структури карток товарів.
* **CSS Grid:** Реалізовано адаптивну сітку каталогу товарів та макет сторінки з бічною панеллю фільтрів (Sidebar + Content).
* **Media Queries (@media):** Забезпечено повну адаптивність для мобільних пристроїв (планшети, телефони). Меню та сітки автоматично перебудовуються у вертикальний формат.
* **CSS Variables (var(--name)):** Використано змінні для збереження кольорової гами (Брендбук) та шрифтів, що дозволяє легко змінювати тему сайту.
* **CSS-only Modals:** Реалізовано модальне вікно входу/реєстрації за допомогою псевдокласу `:target`, без використання JS.
* **Form Validation:** Стилізація валідації форм за допомогою псевдокласів `:valid` та `:invalid`.

### Лабораторна робота 4 (JavaScript & DOM)
Додано клієнтську логіку та інтерактивність за допомогою **Vanilla JavaScript**.

* **DOM Manipulation:**
    * Динамічна зміна стилів (підсвітка цін).
    * Програмне додавання нових елементів (блок "Акція").
    * Виведення поточної дати у футері.
* **Event Handling (Події):**
    * **Dark Mode:** Перемикач світлої/темної теми зі зміною іконки.
    * **Accessibility:** Зміна розміру шрифту клавішами `ArrowUp` / `ArrowDown`.
    * **UI Effects:** Акордеон ("Читати більше") та JS-ховер ефекти для меню.
* **Form Validation:**
    * Перехоплення події `submit`.
    * Валідація полів (Ім'я, Email, Повідомлення) з виведенням помилок під полями.
* **Web Storage API:** Використання `localStorage` для збереження обраної теми користувача.

## 📂 Структура проєкту

### HTML (Сторінки)
- `index.html` — Головна сторінка (Hero-секція, презентація).
- `catalog.html` — Каталог товарів (Grid-сітка, фільтри).
- `contacts.html` — Контакти (JS-валідація форми).
- `cart.html` — Кошик користувача.
- `login.html` — Сторінка входу та реєстрації.

### CSS (Стилі)
Всі стилі знаходяться у папці `css/` та об'єднані через `@import`.
- `style.css` — Головний файл, точка входу.
- `base.css` — Змінні кольорів, шрифти, скидання.
- `layout.css` — Сітка, хедер, футер, адаптивність.
- `components.css` — UI-елементи (кнопки, форми, картки).

### JavaScript
- `js/main.js` — Основний скрипт, що містить логіку взаємодії з DOM, обробники подій та валідацію.

### Ресурси
- `images/` — Папка із зображеннями товарів та банерів.

## 🚀 Як запустити
1. Завантажте репозиторій.
2. Відкрийте файл `index.html` у будь-якому сучасному браузері.
